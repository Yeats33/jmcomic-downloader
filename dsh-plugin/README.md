# DSH 混合插件（实验版）

这是独立于原 Tauri 应用的 DeepSeek Harness 插件包：侧栏提供匿名搜索、漫画和章节详情、在线阅读及单章节下载；Host 提供 `jmcomic_search`、`jmcomic_comic`、`jmcomic_chapter`、`jmcomic_download_chapter` 工具。插件重新实现了必要的 JM API 和图片处理，不是把 Tauri 界面直接嵌入 DSH；原应用及其数据不变。

## 当前范围和限制

- 目前只针对 DSH **0.2.2-rc.1** 的插件接口开发。宿主的工具注册、认证 Gateway 和客户端插槽可能在其他版本发生变化。
- 搜索和在线阅读使用匿名接口。搜索结果以封面卡片分页显示，每页最多 20 项。阅读入口位于章节详情，支持左右方向键或按钮翻页、页码跳转、上一章/下一章、缩放和失败重试；默认顺序预读当前页之后最多 10 页，界面显示实际缓冲数量；预读失败的页面会在进入时自动再试一次。当前页及预读图片的 Blob 缓存总量上限为 64 MiB，达到上限会暂停预读；切换章节或退出时取消请求并释放缓存。暂不支持调整预读页数或同步阅读进度。章节下载是同步操作、逐页处理。没有持久任务队列、续传、批量下载、暂停/恢复、收藏夹、登录、本地阅读、导出、进度广播或原应用数据迁移。
- 网络协议和服务域名由上游控制，可能失效。模板无法严格识别 `scramble_id` 时会报错，不会静默使用猜测值。当前不支持线路自动切换与代理设置。
- 下载根目录默认空，因而下载默认**禁用**。用户需先自行创建一个仅受信任用户可写的专用目录，再在插件配置中将 `downloadRoot` 设为其规范化绝对路径；路径及其祖先不能为符号链接。绝不使用原应用的目录或队列来规避不同进程并发写入问题。
- 每章写入 `downloadRoot/chapter-<章节ID>`；已存在的目录会报错，绝不会续传或覆盖。完成后写入 `.complete.json`。普通失败或取消尽量清理本次创建的文件；进程崩溃等情况可能留下不完整目录，需要用户检查后自行处理。
- Host 插件直接运行在 DSH 进程中，下载会写入配置的目录，**不受会话工作区文件沙箱约束**。请仅在信任插件且接受此行为时配置目录；AI 下载工具还会逐次请求用户审批，审批被拒绝、禁用或不可用时不会写入。界面按钮由用户直接点击启动。Node 没有跨平台 `openat`，路径检查不能防御拥有目录写权限的恶意进程同时替换路径。
- 取消是协作式请求；网络或 Host 可能稍后才停止，关闭面板后应检查目录。只接受已知 CDN 的图片，不跟随重定向；文件数、图像像素和单文件大小均有上限。GIF 保留原始数据；下载时 WebP 重排后默认编码为 JPEG，在线阅读时静态图片重排后编码为 PNG。
- 在线阅读通过 DSH 已认证的同源 Gateway 传输图片，不落盘；每页最多接收和输出各 16 MiB，解码总帧像素上限 2,000 万。后端限制并发，并在关闭阅读器时尝试取消请求；正在运行的原生解码需结束后才能释放处理槽。
- 不读取、复制或保存原应用的用户名、密码或阅读记录。第三方服务的内容与响应均不可信；请遵守适用法律与服务条款。

## 从 Release 安装

在 DSH 插件管理器中选择安装本地文件或输入 Release 附件的 URL，选择 `local-dsh-jmcomic-0.1.1.tgz` 并启用。也可以下载附件后指定其绝对路径：

```sh
dsh plugin --profile <目标-profile> add /绝对路径/local-dsh-jmcomic-0.1.1.tgz
```

请选择实际运行 GUI 的 profile（桌面应用通常是 `desktop`）。安装需要联网解析依赖，压缩包不是离线依赖包；`sharp` 使用与操作系统和 CPU 架构匹配的预编译组件。安装器如要求运行额外脚本，请先审查后自行决定是否批准。当前仅针对 DSH 0.2.2-rc.1 开发和测试，其他版本可能不兼容。

## 从源码安装（本地链接）

1. 在仓库的 `dsh-plugin` 目录执行 `pnpm install --ignore-scripts --frozen-lockfile`。`sharp` 使用平台原生依赖；若平台缺少兼容的预编译包，下载或在线阅读会报错，请查看其安装说明。不要盲目批准额外安装脚本。
2. 在目标 DSH profile 的插件管理器中安装本目录的本地链接（`link:<dsh-plugin 的绝对路径>`），并启用该 bundle。此操作会更改目标 profile；安装脚本如有待批准项，须由使用者自行审查批准。也可由使用者通过 DSH 官方插件管理 CLI 安装到指定 profile，注意选择当前 GUI 实际使用的 profile。
3. 本 bundle 的 `cordis.patch.yml` 为 `apiDomain` 指定 `www.cdnbea.net`（源码 schema 的回退值为 `www.cdnzack.cc`）；`timeoutMs` 默认 15000，`downloadRoot` 默认空字符串。当前版本没有图形化配置表单。本地链接安装可修改本插件的 bundle patch 中 `config`，并在插件管理器中停用再启用 bundle，以重新加载配置；不要直接改写用户 profile 文件。启用下载前，`downloadRoot` 必须是事先存在的专用绝对目录。
4. 如管理器报告需要重启，请重启对应 DSH 宿主，并刷新当前 GUI。打开侧栏「jmcomic」。新建会话后检查 `jmcomic_*` 工具是否在当前 Agent/preset 可见；已有会话可能保留旧 preset，权限规则也可能隐藏工具。

安装/启用、真实 GUI 展示和真实服务联通需在目标 DSH 环境中验证。代码仓库中的离线测试不能代替这些检查；不会因为代码文件存在就自动安装或更新正在运行的 GUI。

## 开发测试（源码仓库）

以下命令针对源码仓库；发布的 npm tar 包不包含源码锁文件，请使用插件管理器直接安装发布包。

```sh
cd dsh-plugin
pnpm install --ignore-scripts --frozen-lockfile
pnpm test
# 使用本机已安装的 DSH 包运行内存宿主集成测试：
node --test integration/*.test.js
```

集成测试的本机 DSH 路径配置和范围见 `integration/README.md`。测试不要求真实 JM 网络，原应用构建仍可在仓库根目录执行 `pnpm build`。
